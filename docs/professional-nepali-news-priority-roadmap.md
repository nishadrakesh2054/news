# Professional Nepali News Portal Priority Roadmap

This is a planning document for reading and discussion only. No code has been changed.

## Goal

Turn the current news portal into a professional Nepali media website comparable in user trust, design polish, and content experience to Ratopati, OnlineKhabar, or Setopati.

## Roadmap Overview

### Phase 1: Improve the homepage experience

Priority items:
- redesign homepage hierarchy for clearer editorial priority
- create Top Stories / Latest / Most Read blocks
- make breaking and live sections more visually prominent
- refine layout for mobile readability
- add stronger photo and video blocks

Target outcome:
- users immediately understand what is most important
- homepage feels premium and structured

### Phase 2: Strengthen category and content discovery

Priority items:
- category landing pages with filters
- subcategory navigation
- topic clusters and tag-based discovery
- better internal linking between related stories
- breadcrumb and archive pages

Target outcome:
- readers can explore categories easily
- content feels organized and searchable

### Phase 3: Build trust and authority

Priority items:
- journalist profile pages
- editorial board and newsroom pages
- author listings and bylines
- transparent publication policy
- contact and newsroom information improvements

Target outcome:
- audience sees the publication as trustworthy and established
- branding becomes stronger than a generic news blog

### Phase 4: Increase reader engagement

Priority items:
- comment moderation and user identity
- reaction tools on articles
- newsletter subscription forms
- push-style alerts and daily digest
- saved articles and personalized reading

Target outcome:
- more return traffic
- stronger audience retention and loyalty

### Phase 5: Expand multimedia and live coverage

Priority items:
- video section on homepage
- photo gallery pages
- live stream blocks with clear timestamps
- special coverage landing pages
- video/article cross-promotion

Target outcome:
- portal feels modern and dynamic
- more formats available beyond text articles

### Phase 6: Monetization and ad UX

Priority items:
- in-content ads
- sticky sidebar ads
- branded content areas
- sponsor modules and category placements
- ad performance analytics

Target outcome:
- sustainable revenue without harming UX

### Phase 7: SEO and performance improvement

Priority items:
- schema markup
- article metadata improvement
- related article engine
- page speed optimization
- social preview management
- sitemap and crawl strategy

Target outcome:
- stronger visibility in search and social discovery

## Recommended feature priority list

### Must-have for early upgrade
1. Homepage editorial hierarchy
2. Elite category page structure
3. Premium live news banner and ticker
4. Newsletter / email capture
5. Author and newsroom profile pages
6. SEO improvements and structured metadata

### Important for next stage
7. Video/photo gallery modules
8. Comment and reaction systems
9. Better ad placement strategy
10. Analytics dashboard and audience insights

### Nice-to-have after growth
11. Personalized recommendations
12. Push notifications
13. Audio news/player expansion
14. Premium content and membership options

## Safe, non-destructive implementation strategy

To solve the feature gap without breaking the current portal, the changes should be added in a layered, low-risk way:

1. Add new sections without removing current homepage blocks
2. Extend existing CMS fields instead of rewriting the data model
3. Keep current article and category routes working while adding new landing pages
4. Use progressive enhancement for comments, newsletter, author profiles, and ads
5. Ship behind feature flags or admin toggles where possible
6. Keep current published content stable while new modules are introduced
7. Validate functionality on staging before activating new modules on the live site

This approach keeps the current website operational while gradually upgrading quality, trust, and engagement.

## Suggested product focus

The best next direction is to focus on four areas:

- trust: newsroom identity, authors, editorial standards
- urgency: breaking news, live stories, timely coverage
- retention: newsletter, comments, saved content, personalization
- monetization: strategic ad slots and sponsor visibility

## What this project already does well

- article publishing workflow
- live coverage logic
- category blocks
- multilingual publishing support
- utility widgets and editorial sections
- admin management base

## What to add next

The most valuable next additions are not random features. They are the features that make readers trust the brand, come back often, and keep spending time on the portal.

These are:
- stronger homepage hierarchy
- better category navigation
- newsletter and audience retention tools
- journalist/editorial profile system
- richer live coverage and urgency UX
- stronger SEO and content discoverability

## Final Recommendation

Do not chase every possible feature at once. Build in this order:

1. Editorial product polish
2. Reader trust and identity
3. Audience retention tools
4. Monetization quality
5. SEO and discoverability

This sequence will move the portal from a functional news site toward a premium Nepali media brand.
